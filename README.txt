Sulok - Product Prototype
==========================

This package contains a single self-contained HTML file (index.html) with the
full Sulok marketing website + application dashboard prototype:

- Public marketing site (home, platform, solutions, how it works, features,
  pricing, resources, about, contact, privacy, terms, cookies, security,
  AI responsible use)
- Login / signup pages
- Application dashboard (customers, behavior, segments, segment detail,
  personas, value intelligence, campaign generator, Sulok Intelligence
  chat assistant, reports, settings)
- Full English / Arabic bilingual support with RTL layout
- Demo data only - no real backend is connected

How to use:
- Double-click index.html to open it directly in any modern browser, or
- Upload it to any static web host (Netlify, Vercel, GitHub Pages, etc.)
  to make it publicly accessible at your own domain.

This is a front-end prototype for demonstration and user testing purposes.
It is not connected to a live database, authentication system, or AI API.
